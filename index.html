Ad Account Morning Check

One command. Three answers for your morning Meta + Shopify check: yesterday's real contribution margin, day-over-day trend, and the paused-ads-with-spend audit.

↓ Download ZIP

What it does

Section 1

Yesterday's real CM. Revenue, COGS, shipping, processing, returns reserve, ad spend, then the number that matters: contribution margin in dollars and percent.

Section 2

5-day trend. Side-by-side daily CMs so today's number has context. Catches drift, weekday vs weekend patterns, and the days where pre-ad margin tanked.

Section 3

Paused-with-spend audit. Every ad that spent >$50 in the last 7 days that's currently paused. The "good ads stranded" list.

What you need

  • Claude Code
  • Python 3.9+
  • A Meta Marketing API access token (System User token preferred — non-expiring)
  • A Shopify Admin API access token with read_orders, read_products, read_inventory scopes
  • Your unit-economics costs in a JSON file (template included in the ZIP)

How to install it

1

Download the ZIP

Click the button above. Unzip it. You'll see SKILL.md, scripts/morning_check.py, unit-economics.template.json, .env.template, and README.md.

2

Drop the skill into your Claude Code skills folder

Copy SKILL.md and scripts/ into ~/.claude/skills/ad-account-morning-check/ (or your project's .claude/skills/).

3

Set up your tokens

Copy .env.template to .env at your project root and fill in:

click to copyMETA_PAGE_TOKEN=EAA... META_AD_ACCOUNT_ID=act_1234567890 SHOPIFY_STORE=yourstore.myshopify.com SHOPIFY_ACCESS_TOKEN=shpat_...

Use a Meta System User token (Business Suite → System Users → Generate Token) — non-expiring. User tokens expire every 60 days and will silently break this skill when they do.

4

Set up your unit economics

Copy unit-economics.template.json to unit-economics.json and fill in YOUR cost rates: default COGS %, shipping cost, processing %, returns reserve %, currency. These rates are the most important inputs — get them wrong and the CM number lies.

5

Run it
